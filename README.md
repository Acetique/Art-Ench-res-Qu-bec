# Art Enchères Québec
Site statique indépendant pour explorer des œuvres et importer des résultats vérifiés BYDealers, Heffel et Gélineau.

## Publication gratuite
1. Créer un dépôt GitHub public.
2. Ajouter `index.html` à la racine.
3. Dans Settings > Pages, choisir Deploy from a branch, `main`, `/ (root)` puis Save.
4. Attendre la publication de l'adresse GitHub Pages.

## Données
Importer un CSV avec les colonnes indiquées dans `exemple-import.csv`. Les imports sont enregistrés dans le navigateur uniquement. Aucune collecte automatique n'est implémentée. Pour publier une base commune, ajouter un fichier JSON public et une automatisation serveur conforme aux conditions d'accès des sources.
